## 예상 공부 포인트

- **상태 객체 패턴**: `detailState = { planId: null, ... }` — 현재 어떤 패널이 열려있는지 하나의 객체로 관리
- **폼 입력 처리**: `textarea.oninput = () => { ... }` — 입력할 때마다 실시간으로 데이터 반영
- **조건부 렌더링**: 같은 패널을 새 일정 추가 / 기존 일정 수정 두 가지 모드로 재활용하는 방법
- **DOM 요소 재사용**: 패널을 매번 새로 만들지 않고, 내용만 바꿔 보여주는 패턴
