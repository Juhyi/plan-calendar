❓ 사용 설명서

📅 월간 캘린더
  • + 버튼 또는 날짜 클릭 → 일정 추가 모달
  • 일정 클릭 → 우측 상세 패널 열기
  • 일정 ✕ → 즉시 삭제
  • 일정 드래그 → 다른 날짜로 이동 (기간 일정은 전체 기간 shift)
  • ◀ ▶ 버튼 또는 오늘 버튼으로 월 이동
  • 📥 CSV → 현재 월 일정 파일로 내보내기
📝 일정 추가 / 수정
  • 제목 입력 후 Enter 또는 추가 버튼
  • 시작일·종료일 설정 시 기간 스팬 바로 표시
  • 카테고리: 💼 업무 / 🏠 개인 선택
  • 색상 팔레트에서 색상 선택 (카테고리별 별도 팔레트)
🗂 일정 상세 패널
  • ✏️ 수정 → 내용·기간·색상 변경
  • 📋 복사 → 날짜를 선택해 동일 일정 복사
  • ✅ 완료 → 완료 처리 (세부일정 없는 경우만 표시)
  • 하단 입력창에 세부일정 입력 후 Enter → 세부일정 추가
  • 세부일정 체크박스 → 완료 처리 + 완료 날짜 자동 기록
  • 세부일정 텍스트 더블클릭 → 수정 모드
  • 완료 날짜 클릭 → 날짜 직접 변경
  • ▲ ▼ 버튼 → 세부일정 순서 변경
  • 세부일정 비율에 따라 일정 색상이 보라색으로 선형 변화
📁 프로젝트
  • 헤더 📁 프로젝트 → 프로젝트 관리 다이얼로그
  • 이름·기간·색상·카테고리 설정 후 추가
  • 진행 중 프로젝트는 달력 기간 전체에 컬러 배너로 표시
  • 배너 클릭 → 프로젝트 상세 패널 열기
  • 상세 패널에서 + 일정 추가 → 프로젝트에 일정 직접 등록
  • 달력 일정을 드롭존에 드래그 → 프로젝트에 연결
  • 연결된 일정 클릭 → 해당 일정 상세 패널로 이동
  • 연결 일정의 완료 비율이 프로젝트 진행률로 계산
  • 달력에서 💼 업무 / 🏠 개인 필터 시 프로젝트 배너도 함께 필터링
🗒️ 메모 패널
  • 헤더 📝 메모 → 좌측 슬라이드 패널
  • 입력 후 Enter → 메모 추가
  • 체크박스 → 완료 처리 (목록 하단으로 이동)
  • 텍스트 더블클릭 → 수정 모드
  • ✓ 완료 항목 삭제 → 완료된 메모 일괄 삭제
  • 메모를 달력 날짜 위로 드래그 → 해당 날짜 일정 추가 모달로 전환 (메모는 자동 삭제)
  • 완료된 메모는 드래그 불가
📋 주간 캘린더
  • 화면 하단에 7일 컬럼 레이아웃으로 표시
  • ◀ ▶ 버튼으로 이전/다음 주 이동, 이번 주 버튼으로 현재 주 이동
  • 각 날짜에 + 버튼으로 일정 추가, 일정 클릭 시 상세 패널 열기
  • 월간 캘린더와 동일한 데이터를 공유
🏷️ 카테고리 필터
  • 헤더 전체 / 💼 업무 / 🏠 개인 토글로 달력·주간 뷰 필터링
  • 업무: 쿨톤 파란 계열 색상 팔레트
  • 개인: 웜톤 주황·핑크 계열 색상 팔레트
  • 필터 전환 시 요일 헤더·주간 헤더 배경색도 함께 변경
⌨️ 키보드 단축키
Enter입력 저장 (일정·세부일정·메모 추가)
Shift + Enter줄바꿈 입력
Esc모달 닫기 / 수정 취소
🗓️ 공휴일
  • Nager.Date API를 통해 자동 로드 (30일 캐싱)
  • ⚙️ 설정 변경 → 🗓 공휴일 데이터 수동 업데이트에서 iCal URL 입력 또는 .ics 내용 직접 붙여넣기 가능
☁️ 데이터 저장
  • 일정·메모·프로젝트는 Firebase Realtime DB에 실시간 저장·동기화
  • 상단 연결됨 / 연결 중으로 동기화 상태 확인
  • ⚙️ 설정 변경에서 Firebase 설정 변경 가능
