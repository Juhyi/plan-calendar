❓ 사용 설명서

📅 월간 캘린더
  • + 버튼 또는 날짜 클릭 → 일정 추가 모달
  • 일정 클릭 → 우측 상세 패널 열기
  • 일정 ✕ → 즉시 삭제
  • 일정 드래그 → 다른 날짜로 이동
  • 일정 A를 일정 B 위에 드래그 → B의 세부일정으로 추가
  • ◀ ▶ 버튼으로 월 이동
🗂 세부일정 패널
  • 일정 클릭 → 우측 세부일정 패널
  • 패널이 열린 상태에서 다른 일정 드래그 → 세부일정으로 추가
  • 세부일정 행 드래그 → 캘린더 날짜에 드롭 → 독립 일정으로 분리
  • 완료된 일정을 세부일정으로 추가 시 완료 상태 유지
📁 프로젝트
  • 사이드바 📁 프로젝트 → 프로젝트 관리
  • 프로젝트 상세에서 📅 일정변환 → 기간 일정으로 변환
  • 달력 일정을 드롭존에 드래그 → 프로젝트에 연결
